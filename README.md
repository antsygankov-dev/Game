Grid Tower Defense: JS Core & Web Widget (Лабораторные работы №4 и №5)

Данный репозиторий содержит реализацию игрового проекта «Кооперативная оборона: Башни и Энергия» (Вариант 23) на языке JavaScript (ES6+). 
Проект разделен на две части: независимое математическое ядро (ЛР4) и интерактивный веб-виджет (ЛР5) на HTML5 Canvas.

======================================================================
СТРУКТУРА ПРОЕКТА
======================================================================

* js_core/ — Ядро игры (ЛР4). Работает в Node.js без привязки к интерфейсу.
* js_widget/ — Веб-виджет (ЛР5). Подключает ядро и реализует графику.

======================================================================
ЧАСТЬ 1. JAVASCRIPT CORE (ЛАБОРАТОРНАЯ РАБОТА №4)
======================================================================

Математическое ядро игры, портированное с Python. Полностью независимо от интерфейса (браузера) и проверяется через Node.js.

--- Запуск самопроверки (Selftest) ---
В ядре реализован 21 автоматический тест (геометрия, формулы, состояния монстров, кулдауны, MST).
1. Откройте терминал в папке js_core.
2. Выполните команду:
   node selftest.js

Ожидаемый результат: все проверки зеленые, в конце строка "=== RESULT: 21 PASSED, 0 FAILED ===".

--- Реализованные алгоритмы (ЛР4) ---
1. Расстояние между точками: Math.hypot(x2 - x1, y2 - y1) — для поиска целей и расчета кабеля.
2. Алгоритм Прима (MST): Класс EnergyGrid строит минимальное остовное дерево для соединения башен с генератором.
3. Конечный автомат (FSM): Состояния монстра Moving -> ReachedEnd / Dead.
4. Коллизии без мутации: Метод Rect.move(dx, dy) возвращает новую копию объекта, защищая оригинал от изменений.

======================================================================
ЧАСТЬ 2. WEB WIDGET (ЛАБОРАТОРНАЯ РАБОТА №5)
======================================================================

Интерактивный фронтенд на HTML5 Canvas, который использует готовое ядро из ЛР4.

--- Запуск проекта ---
Из-за использования ES-модулей (import/export) открытие index.html двойным кликом невозможно. Нужен локальный сервер.
1. Откройте терминал в папке js_widget.
2. Запустите сервер:
   * Через Python: python -m http.server 8000
   * Через Node.js: npx http-server -p 8000
3. Откройте в браузере: http://localhost:8000
ВАЖНО: Не закрывайте терминал с сервером во время игры.

--- Управление ---
* Левая кнопка мыши — построить башню на пустой клетке (строительство на дороге заблокировано).
* Клавиша R — перезапустить игру.
* Кнопки на панели справа — вызов встроенных сценариев.
* Консоль браузера (F12) — доступ к объекту Game.

--- Параметры цикла и механик (ЛР5) ---
* Фиксированный шаг симуляции: 16.67 мс (60 FPS). Реализован через накопитель (accumulator) для равномерного шага логики.
* Ввод: Массив-флаги (this.keys). События keydown/keyup только меняют флаг, а игровой цикл опрашивает его.
* Туман войны: Радиус видимости 200 пикселей вокруг курсора (через globalCompositeOperation = 'destination-out').
* Анимация: Взрывы и зеленые/красные HP-бары монстров реализованы через rgba(..., alpha).

--- Таблица вызываемых сценариев ---
Сценарии — это функции, меняющие состояние игры. Вызываются из кнопок или консоли.

| Название сценария | Действие | Вызов из консоли (F12) |
| :--- | :--- | :--- |
| giveGold(amount) | Добавляет золото | Game.scenarios.giveGold(500) |
| clearEnemies() | Удаляет всех монстров | Game.scenarios.clearEnemies() |
| toggleFog() | Включает/выключает туман | Game.scenarios.toggleFog() |
| explosion(x, y) | Создает эффект взрыва | Game.scenarios.explosion(400, 300) |

======================================================================
ИНТЕГРАЦИЯ (КАК ЭТО РАБОТАЕТ ВМЕСТЕ)
======================================================================
Виджет не дублирует код. Он импортирует классы Enemy, Tower, EnergyGrid и GameField из модулей ядра.
Виджет (scripts/widget.js) отвечает только за:
1. Ввод (массив-флаги).
2. Отрисовку примитивами Canvas.
3. Анимацию эффектов (rgba).
4. Обновление DOM-элементов (HUD через textContent).
