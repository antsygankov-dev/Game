# Grid Tower Defense: JavaScript Core (Лабораторная работа №4)

Данный репозиторий содержит математическое ядро игры «Кооперативная оборона: Башни и Энергия» (Вариант 23), портированное с Python на современный JavaScript (ES6+). 

Ядро полностью независимо от интерфейса (браузера) и работает в среде Node.js. Отрисовка (Canvas) будет реализована в следующей лабораторной работе (ЛР5).

## 🛠 Стек технологий
* **Язык:** JavaScript (ES6+)
* **Среда выполнения:** Node.js 18+
* **Архитектура:** ES-модули (`import` / `export`), объектно-ориентированный подход.

## 📂 Структура проекта

Весь код находится в папке `js_core`:
* `package.json` — конфигурация проекта (поддержка ES-модулей).
* `selftest.js` — скрипт автоматической самопроверки (21 тест).
* `js/` — директория с модулями ядра:
  * `constants.js` — игровые константы (баланс башен/монстров, координаты генератора и пути).
  * `rect.js` — класс прямоугольника `Rect` для обработки коллизий.
  * `math_utils.js` — математические функции (расчёт расстояний).
  * `enemy.js` — класс монстра (содержит конечный автомат состояний).
  * `tower.js` — класс башни (поиск цели, кулдаун атаки).
  * `energy_grid.js` — алгоритм построения энергосети (MST).
  * `game_field.js` — игровое поле, управляющее циклом симуляции.

## 🧮 Реализованные алгоритмы и формулы

1. **Расстояние между точками (Теорема Пифагора)**
   `distance = Math.hypot(x2 - x1, y2 - y1)`
   *Используется для поиска ближайшего монстра башней и расчёта длин кабелей.*

2. **Расстояние от точки до отрезка**
   Вычисляется через проекцию вектора. 
   *Используется для проверки коллизий: запрет на строительство башен поверх тропы.*

3. **Минимальное остовное дерево (Алгоритм Прима)**
   Класс `EnergyGrid` строит MST между генератором и башнями. 
   *Стоимость кабеля:* `TotalCost = Sum(distances) * CableCostPerPx`.

4. **Конечный автомат (FSM) для монстров**
   Состояния монстра: `Moving` (движение по точкам пути) ➔ `ReachedEnd` (дошёл до базы) / `Dead` (убит башней).

5. **Коллизии без мутации**
   Метод `Rect.move(dx, dy)` возвращает **новый объект** `Rect`, оставляя оригинал неизменным (по аналогии с `pygame.Rect.move`), что защищает от случайного изменения состояния при проверке.
