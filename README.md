# Grid Tower Defense: JavaScript Core (Лабораторная работа №4)

Данный репозиторий содержит математическое ядро игры «Кооперативная оборона: Башни и Энергия» (Вариант 23), портированное с Python на современный JavaScript (ES6+). 

Ядро полностью независимо от интерфейса (браузера) и работает в среде Node.js. Отрисовка (Canvas) будет реализована в следующей лабораторной работе (ЛР5).

## 🛠 Стек технологий
* **Язык:** JavaScript (ES6+)
* **Среда выполнения:** Node.js 18+
* **Архитектура:** ES-модули (`import` / `export`), объектно-ориентированный подход.

## 📂 Структура проекта

Весь код находится в папке `js_core`:
* `package.json` — конфигурация проекта (поддержка ES-модулей).
* `selftest.js` — скрипт автоматической самопроверки (21 тест).
* `js/` — директория с модулями ядра:
  * `constants.js` — игровые константы (баланс башен/монстров, координаты генератора и пути).
  * `rect.js` — класс прямоугольника `Rect` для обработки коллизий.
  * `math_utils.js` — математические функции (расчёт расстояний).
  * `enemy.js` — класс монстра (содержит конечный автомат состояний).
  * `tower.js` — класс башни (поиск цели, кулдаун атаки).
  * `energy_grid.js` — алгоритм построения энергосети (MST).
  * `game_field.js` — игровое поле, управляющее циклом симуляции.

## 🧮 Реализованные алгоритмы и формулы

1. **Расстояние между точками (Теорема Пифагора)**
   `distance = Math.hypot(x2 - x1, y2 - y1)`
   *Используется для поиска ближайшего монстра башней и расчёта длин кабелей.*

2. **Расстояние от точки до отрезка**
   Вычисляется через проекцию вектора. 
   *Используется для проверки коллизий: запрет на строительство башен поверх тропы.*

3. **Минимальное остовное дерево (Алгоритм Прима)**
   Класс `EnergyGrid` строит MST между генератором и башнями. 
   *Стоимость кабеля:* `TotalCost = Sum(distances) * CableCostPerPx`.

4. **Конечный автомат (FSM) для монстров**
   Состояния монстра: `Moving` (движение по точкам пути) ➔ `ReachedEnd` (дошёл до базы) / `Dead` (убит башней).

5. **Коллизии без мутации**
   Метод `Rect.move(dx, dy)` возвращает **новый объект** `Rect`, оставляя оригинал неизменным (по аналогии с `pygame.Rect.move`), что защищает от случайного изменения состояния при проверке.

## 🚀 Запуск проекта

Из-за использования ES-модулей (`import`/`export`), открытие файла `index.html` напрямую (через `file://`) невозможно из-за политики безопасности браузеров. Необходим локальный статический сервер.

1. Откройте терминал в папке `js_widget`.
2. Запустите сервер любым удобным способом:
   * **Через Python:** `python -m http.server 8000`
   * **Через Node.js:** `npx http-server -p 8000`
3. Откройте в браузере: **http://localhost:8000**

> ⚠️ **Важно:** Не закрывайте терминал с запущенным сервером во время игры.

## 🎮 Управление
* **Левая кнопка мыши** — построить башню на пустой клетке (строительство на дороге заблокировано).
* **Клавиша R** — перезапустить игру (сброс золота и волн).
* **Кнопки на панели справа** — вызов встроенных сценариев.
* **Консоль браузера (F12)** — прямой доступ к объекту `Game` для вызова сценариев.

## ⚙️ Параметры игрового цикла и механик
* **Фиксированный шаг симуляции:** 16.67 мс (60 FPS). Реализован через накопитель времени (`accumulator`) в функции `gameLoop`. Логика шагает равномерно, независимо от частоты кадров браузера.
* **Отрисовка:** Осуществляется каждый кадр через `requestAnimationFrame`.
* **Ввод:** Реализован через массив-флаги (`this.keys`). События `keydown`/`keyup` только меняют флаг, а цикл опрашивает его в каждом кадре.
* **Радиус видимости (Туман войны):** 200 пикселей вокруг курсора мыши. Реализован через `globalCompositeOperation = 'destination-out'`.
* **Анимация эффектов:** Взрывы (расширяющиеся круги) и HP-бары монстров реализованы через `rgba(..., alpha)` с плавным затуханием.

## 📜 Таблица вызываемых сценариев

Сценарии — это именованные функции, меняющие состояние виджета. Они собраны в реестр `scenarios.js`.

| Название сценария | Действие | Вызов из консоли (F12) |
| :--- | :--- | :--- |
| `giveGold(amount)` | Добавляет указанное количество золота | `Game.scenarios.giveGold(500)` |
| `clearEnemies()` | Удаляет всех монстров с поля | `Game.scenarios.clearEnemies()` |
| `toggleFog()` | Включает/выключает туман войны | `Game.scenarios.toggleFog()` |
| `explosion(x, y)` | Создает эффект взрыва в координатах | `Game.scenarios.explosion(400, 300)` |

## 🧩 Интеграция с ядром (ЛР 4)
Виджет не дублирует игровую логику. Классы `Enemy`, `Tower`, `EnergyGrid` и `GameField` импортируются из модулей ядра ЛР 4 (скопированы в папку `js/`). 
Сам виджет (`scripts/widget.js`) отвечает только за:
1. Ввод (массив-флаги).
2. Отрисовку примитивами Canvas.
3. Анимацию эффектов (`rgba`).
4. Обновление DOM-элементов (HUD через `textContent`).
